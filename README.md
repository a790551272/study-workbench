# 四年级上册全科学习工作台

适用：小学四年级 · 语文（部编人教版四上）、数学（人教版四上）、英语（人教PEP四上）

## 使用方式

**本地使用**：双击 `index.html` 即可打开（推荐 Chrome / Edge）。所有数据（星星、错题、设置）保存在本机浏览器里，不上传任何服务器。

**手机 / 平板使用**：已发布在线链接，用浏览器打开即可（见下方"在线地址"）。

## 六大模式

| 模式 | 说明 |
|---|---|
| 模式1 每日任务 | 周一至周五，自动生成 20 分钟学习清单（5 项必做 + 3 项选做拓展） |
| 模式2 周末专项 | 60 分钟分模块：语文 25 → 休息 5 → 数学 25 → 英语 10 |
| 模式3 听写默写 | 语文词语 / 英语单词分批听写，语音报读，写完输入"写完"进入下一批，最后统一核对 |
| 模式4 刷题练习 | 按学科、单元选题，先出题 → 作答 → 再对答案（口算 / 竖式 / 填空 / 应用题 / 单词 / 句型 / 阅读理解） |
| 模式5 错题复习 | 简易艾宾浩斯：做错 → 3 天后复习 → 再对 → 7 天后复习 → 再对 → 出库 |
| 模式6 背诵检测 | 9 首古诗 + 课文段落抽查，先背再对照，流利完整额外 +⭐1 |

其余页面：**⭐ 星星与奖励**（总台账、兑换、规则）、**📕 错题本**、**⚙️ 设置**。

## 星星规则

- 完成一次平日 20 分钟完整任务 ⭐2；周末 60 分钟完整任务 ⭐5
- 听写/默写全对 +⭐1（错 1～2 个不加不减；错 3 个及以上不额外加分）
- 错题重做全对，每道 +⭐0.5
- 流利完整背诵 +⭐1；主动认真思考可酌情 +⭐1
- 中途放弃本次不得星；敷衍乱写 −⭐1；多次提醒仍走神 −⭐1
- 最低 0 颗，不会出现负数

兑换清单（设置 → ⭐ 星星与奖励 → 家长修改清单，可自行改）：
⭐10 额外 30 分钟自由阅读 ｜ ⭐20 周末户外游玩 ｜ ⭐35 自选小文具/课外书 ｜ ⭐50 一次小愿望

## 家长企微群推送

1. 打开「⚙️ 设置」，填入企微群机器人 Webhook 地址；
2. 每次学习结束点「🏁 结束学习，结算星星」，结算后点「📤 推送到家长企微群」；
3. 小结包含：今日任务、学习情况、错题记录、本次获得星星、累计星星。

> 说明：浏览器直连企微接口常被跨域（CORS）拦截。若推送失败，请点「📋 复制小结」粘贴到群里；或在本地用命令行推送：
> ```
> node tools/wecom_push.js <webhook地址> <小结内容>
> ```
> 也可把 webhook 存到 `tools/webhook.txt`、小结存到 `tools/push.txt`，直接运行 `node tools/wecom_push.js`。

## 文件结构

```
index.html            页面骨架
assets/style.css      样式
js/data-chinese.js    语文题库（8 单元词语、9 首古诗、背诵篇目、阅读理解、小练笔）
js/data-math.js       数学题库（8 单元，口算/竖式随机生成，不含方程）
js/data-english.js    英语题库（6 单元单词+音标+句型+衡水体提示）
js/core.js            存储 / 星星台账 / 错题艾宾浩斯 / 计时器 / 小结推送
js/app.js             六大模式交互
tools/wecom_push.js   命令行企微推送
```

## 出题原则

- 严格按四上课标，不超纲；数学只使用算术方法，不使用方程。
- 先出题、等作答、再给答案，答案不提前泄露。
- 语文听写、英语单词听写均分批进行，等待孩子回复"写完"再继续。
